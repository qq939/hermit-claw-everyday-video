Clawra Selfie — AI 自拍技能

基于 github.com/SumeLabs/clawra 的开源自拍功能。需要 fal.ai API Key。

配置

从 Git 安装

克隆 GitHub 仓库到本地 skills/ 目录

从 npm 安装

通过 npx 安装全局 CLI 技能包

关于 Skill 配置模块

本模块提供交互式技能管理功能，从 Clawra 项目汲取灵感，适配到 Hermit-Claw / Claude Code 环境。

功能说明
技能检测扫描本地 skills/ 和 ~/.claude/skills/ 目录
配置管理保存 API Key、环境变量到 config/skills.json
身份注入将技能描述写入 IDENTITY.md / SOUL.md
Git 安装git clone --depth 1 安装技能仓库
Clawra 适配专为 clawra-selfie 提供的一键配置

配置文件位置

文件用途
config/skills.json所有技能的配置存储
skills/<name>/技能代码目录
skills/<name>/.env技能环境变量
IDENTITY.md身份文件（注入技能描述）
SOUL.md灵魂文件（注入技能描述）
